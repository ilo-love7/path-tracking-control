## §3 调试战记（本项目核心坑，全部已修）

1. **CasADi IPOPT 插件 DLL error 126**：wheel 自带全部依赖 DLL，但 Windows 下插件 `LoadLibrary` 找不到同目录依赖。
   - `os.add_dll_directory()` 会把 DLL 搜索切到 `LOAD_LIBRARY_SEARCH_*` 语义，**反而丢同目录依赖** —— 不要用；
   - 只需把 casadi 目录 prepend 到 `os.environ["PATH"]` 且**必须早于 import casadi**（模块顶层执行）；
   - 另一个隐蔽杀手：`from .path import Path` **遮蔽了 `pathlib.Path`**，`Path(spec.origin)` 抛 TypeError 被 `except: pass` 静默吞掉 → PATH 注入无效。用 `FsPath` 别名。

2. **MPC 动力学分量错位**：状态序 [x,y,v,ψ] 但 rhs 写成 `[v cosψ, v sinψ, v tanδ/L, a]`（ψ̇ 与 v̇ 互换）→ 求解器"用转向管速度、用加速管航向"，直线路径第 2 步起打满舵。修正为 `[v cosψ, v sinψ, a, v tanδ/L]`。

3. **CasADi reshape 列主序 vs numpy flatten 行主序**：`X`/`U`/`x_ref` 展平进 `p`/`w0` 必须 `order="F"`，否则参考轨迹按分量交错错位、初值动态不可行，IPOPT 陷入 restoration（单解 30 s）。

4. **compute() 用 hint 当索引**：`s0 = path.s[ref_idx]`（ref_idx 是 nearest_index 的 hint）应为 `idx = nearest_index(...); s0 = path.s[idx]`，否则参考起点落在车后方。

5. **solve_ms 双重 ×1000**：compute 返回 ms，metric_pack 又 ×1000 → 报表 8 s/解的假象（实际 5–6 ms）。

## §4 结果要点

- 低速 MPC 最优（DLC 0.0040 m / 环形 0.0113 m）；高速 PP 最优（0.0081 / 0.0203 m），MPC 视野不足退化（lat_max 0.75 m、steer_rate 15 倍）。
- Stanley 平滑但恒曲率稳态误差 0.13 m。MPC 求解 5–6 ms/步可部署。
- 「速度反转」现象是本报告最有信息量的发现：预测视野/路径变化尺度之比决定 MPC 优势区间。

### 7.2 调试战记（v1.1 新坑）

1. **前轴误差 + 曲率前馈 = 双重计入**：δ_ff=atan(L·κ) 已含曲率，前轴误差项在稳态又给出 ~L·κ 的贡献 → 环形发散至 1.2 m。改**后轴误差** + FF 后收敛至 0.004 m（原版保持前轴误差对齐 PythonRobotics）。
2. **clothoid 单向 κ 剖面画不出 S 弯**（y 不穿负）：改三段三角 bump（yaw_up=0.5 反向 yaw_down=0.7），航向 ±摆动、y 穿两侧。
3. **迷你 YAML 解析器注释剥离顺序 bug**：`clothoid_s:  # comment` 被判成标量 None → `val.split("#")[0].strip()` 必须先于空值判断。
4. **MPC horizon 加长反而崩坏**（E2/E6 诊断）：N≥10 误差放大 12–43 倍且与 term_w 无规律交互，IPOPT 在长视野非凸 yaw 项下陷入混乱局部解；「加长视野修复速度反转」假说证伪。

### 7.3 结果要点（78 行指标，`results/deepening_metrics.json`）

- E1 动力学迁移：低速 MPC 仍最优但误差 ×10（轮胎侧偏）；**高速环形 MPC 发散 82 m、PP 4.4 m，Stanley 1.5 m 最稳**——模型失配下优化型控制器放大失配。
- E2 MPC-A 全面差于固定 N=5（负结果，如实入报告）。
- E3 Stanley+FF：环形低速 0.132→0.004 m（33×），低速反超 MPC；高速持平。
- E4 clothoid：低速 MPC 最优 0.010；高速 PP 0.018 最优，速度反转重现。
- E5 侧风 MPC 最优；**量测噪声 σ=5cm Stanley 最稳（0.16/0.77 m），PP/MPC 崩坏（5–24 m）**——最近点索引跳动是死穴。
- E6 消融：N=5 时 term_w 单调有害（0→0.022，5→0.106）；最优 MPC(w=0) 高速 0.022/0.093 仍劣于 PP 0.008/0.020，速度反转缓解但未消除。
